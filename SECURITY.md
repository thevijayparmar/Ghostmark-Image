# Security policy

Ghostmark is **not** a proof of authenticity: anyone with the engine can write a mark, and a determined attacker can remove or forge one. It keeps honest metadata alive; it does not defend against a hostile editor.

Found a real vulnerability (for example a crash on a crafted image, or a way to make the reader return a wrong value that passes the CRC)? Please open a private security advisory on GitHub (Security tab, "Report a vulnerability") instead of a public issue.
