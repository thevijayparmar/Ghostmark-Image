# Changelog

## 1.1.0 - 2026-10-26
* **Python engine** (`python/`, numpy only): `mark`, `mark_verified`, `read`, `read_cropped`, `read_perspective`, CLI, 14 tests. Same mark format as the Android and JavaScript engines.
* **Black-and-white study:** nine grey paths on 40 photos; brightness-layer results, demo and charts in the README.
* **Benchmark widened** to 40 photos from 11 cameras (17 iPhone 17 Pro photos added), 480 attacked copies.
* **Licence changed to Apache-2.0** (was a custom attribution licence). `NOTICE` added.
* Logo, social preview, contributing guide, issue templates, CI for the Python engine.

## 1.0.x
* Android engine (Kotlin), mark format 1: colour layer (full record) and brightness layer (location), capture-time self-test, crop search, photo-of-screen reader.
