# Social images v2 (1920x1080): show the output, skip the explaining

Ten pieces, ten styles. Real photos, real decoded values, real measurements (the coordinates in 01, 07 are the photos' own EXIF GPS, written into the pixels and read back from a black-and-white chat copy). Rebuild: `cd tools && PYTHONPATH=../python python make_social_v2.py`.
